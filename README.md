# BD2 连连看

《棕色尘埃 2》Windows 客户端的独立连连看工具，提供实时盘面、配对提示、单步执行和自动本局。

[下载最新版本](https://github.com/MadestSamurai/bd2-sichuan/releases/latest)

## 选择下载

| 版本 | 是否自带运行库 | 使用要求 |
| --- | --- | --- |
| **Portable** | 自带 .NET Desktop Runtime | Windows x64，下载 EXE 后直接运行 |
| **Lite** | 不带运行库，文件更小 | Windows x64，先安装 [.NET Desktop Runtime 8 x64](https://dotnet.microsoft.com/download/dotnet/8.0) |

两版功能和默认设置一致，各提供单 EXE 与包含说明、许可证的 ZIP。Lite 需要 **Desktop Runtime**，只有基础 .NET Runtime 或 ASP.NET Runtime 不够。无需安装 SDK、Python或其他 BD2 工具。

## 使用

1. 从旧工具或其他游戏 Hook 切换时，先关闭旧工具，正常重启游戏。
2. 运行 `BD2Sichuan-0.2.0-Portable-win-x64.exe` 或 Lite 版，点击「连接游戏」。
3. 进入连连看实际盘面，工具会显示方块和配对提示。
4. 点击「执行下一对」或「自动本局」。默认配对间隔 **1000ms**，可在 **50–60000ms** 之间修改，点击「应用间隔」或按回车；运行中也能调整。
5. 点击「立即停止」终止后续操作。关闭窗口也会停止，重新打开不会自动恢复执行。

间隔是相邻两对开始之间的时间，不是同一对内两次点击的间隔；仍受游戏帧率和输入锁约束。暂停或洗牌时等待盘面恢复，清盘后结束本次自动任务。工具不会代点下一关菜单或使用道具。

初次连接会检查本机客户端接口并自动生成采集组件，可能需要等待数秒；普通版本标识和已覆盖的混淆名称变化无需手动重新打包。遇到无法确定的接口变更会停止连接并显示原因。

设置与本机状态保存在 `%LOCALAPPDATA%\BD2Sichuan\`。程序只操作本机游戏，游戏客户端、盘面记录和生成的采集组件不随公开发行包分发。

## 常见情况

- **等待盘面**：进入实际方块盘面；过关菜单、登录页和加载画面没有可操作的盘面。
- **提示已有其他组件**：关闭相关工具，正常重启游戏，再只连接所需工具。
- **无法连接或读游戏路径**：确认只运行一个游戏实例，工具与游戏使用相同权限。
- **接口检查不通过**：更新到最新版；仍失败时可在 Issue 中附错误文字及 compatibility.json，先去除个人路径。不要上传游戏 DLL、账号数据或连接状态文件。
- **只有图标未显示**：图标是辅助显示，不会代替逻辑盘面判断配对。

## 构建与维护

~~~powershell
.\build.ps1 -Locked
.\package.ps1 -Locked
~~~

构建需要 .NET 8 或更新 SDK 的 Windows 环境，不需要安装游戏或访问其他私有项目。`vX.Y.Z` 标签由 GitHub Actions 自动构建、验证和发布双版本。
