## 独立连连看工具

- 实时显示盘面，提供配对提示、执行下一对和自动本局。
- 配对间隔默认 **1000ms**，支持 **50–60000ms**，运行中可调整并保存。
- 暂停或洗牌时等待恢复，清盘后结束；可随时停止，关闭窗口也会停止。
- 连接时自动检查本机客户端接口，无需安装 SDK 或依赖其他 BD2 工具。

| 下载版本 | 自带运行库 | 使用要求 |
| --- | --- | --- |
| **Portable** | 是 | Windows x64，直接运行 |
| **Lite** | 否，体积更小 | Windows x64，安装 [.NET Desktop Runtime 8 x64](https://dotnet.microsoft.com/download/dotnet/8.0) |

两版功能一致，均提供单 EXE 和含说明、许可证的 ZIP。只选择一个版本使用。

**使用方法**：启动游戏 → 打开工具并连接 → 进入连连看盘面 → 点击「自动本局」。

**从旧版或其他 Hook 切换**：先关闭旧工具，正常重启游戏，再使用新版连接。工具不会自动点击下一关菜单或消耗道具。
